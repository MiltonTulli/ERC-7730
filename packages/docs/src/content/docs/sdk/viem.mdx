`viem` is not a dependency of `@erc7730/sdk`. Keccak is `@noble/hashes` and the ABI codec is `ox`.

`decodeViemTypedData` lives on the root. It accepts a viem typed-data definition and does not import `viem` at runtime. Pass a transaction object to `decodeTransaction`. A viem `PublicClient` is still a valid `provider` when the app already depends on viem.

```ts
import { decodeTransaction, decodeViemTypedData, officialOnlyPolicy } from '@erc7730/sdk';

const result = await decodeTransaction(
  { to, data, value, chainId },
  { registry, trust: officialOnlyPolicy(), provider: publicClient },
);

const typed = await decodeViemTypedData(typedDataDefinition, {
  registry,
  trust: officialOnlyPolicy(),
});
```

`attestedPolicy` is imported from `@erc7730/sdk/attest`. Install `viem` only if you import that entry.

Sourcify stays opt-in on the call: `loadVerifiedAbi: sourcifyVerifiedAbiLoader` and `useSourcifyFallback: true`.

API details: [generated docs](/ERC-7730/sdk/api/) for `decodeTransaction` and `decodeViemTypedData`.
