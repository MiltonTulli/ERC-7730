## Runtime vs authoring vs the rest

| Piece | Role |
| --- | --- |
| **`@erc7730/sdk`** | TypeScript **runtime**: validate, resolve, pin the official registry, decode with pluggable trust |
| **`@erc7730/cli`** | **Authoring** binary (`erc7730`) for generate / lint / preview / scaffold / diff |
| **Ledger `python-erc7730`** | Authoring / firmware tooling the **official registry CI** runs |
| **Sourcify `@ethereum-sourcify/clear-signing`** | Reference-oriented TS clear-signing; this toolkit complements it with pin + policy + JS CLI |

Packages are versioned independently (`sdk-v*` / `cli-v*` tags). Generated and Sourcify drafts are **never** `confidence: "high"` under `officialOnlyPolicy()`.
