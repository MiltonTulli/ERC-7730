```bash
npm install @erc7730/sdk
# optional peer for PublicClient / adapters
npm install viem
```

## Entry points

| Import | What you get |
| --- | --- |
| `@erc7730/sdk` | Full runtime. Sourcify is opt-in (`enableSourcifyAbiLoader` or `loadVerifiedAbi`); import does not register a loader. `useSourcifyFallback` defaults to `false` |
| `@erc7730/sdk/lite` | Decode / trust / resolve / path / official registry **without** the Sourcify client, without `generateDescriptor`, and without catalog helpers (`KNOWN_TOKENS`, `SUPPORTED_CHAINS`, `Registry`, …) |
| `@erc7730/sdk/viem` | `decodeViemTransaction` / `decodeViemTypedData` adapters (does not register a Sourcify loader) |

## Quick start

```ts
import {
  createOfficialRegistry,
  decodeTransaction,
  officialOnlyPolicy,
  VENDORED_REGISTRY_COMMIT,
} from '@erc7730/sdk';

const registry = createOfficialRegistry({ pin: VENDORED_REGISTRY_COMMIT });
const result = await decodeTransaction(tx, {
  registry,
  trust: officialOnlyPolicy(),
});

console.log(result.interpolatedIntent ?? result.intent);
console.log(result.source, result.confidence, result.trust.accepted);
```

Prefer [the wallet guide](/ERC-7730/guide/) for prefetch, `ExternalDataProvider`, `trustedTokens`, batch, and UserOp.
