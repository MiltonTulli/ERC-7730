<p class="version-line">This page describes <strong>@erc7730/sdk@{sdkPkg.version}</strong> from this repository checkout. The CLI is versioned independently.</p>

```bash
npm install @erc7730/sdk
# optional peer for PublicClient / adapters
npm install viem
```

## Entry points

| Import | What you get |
| --- | --- |
| `@erc7730/sdk` | Full runtime. Sourcify is opt-in (`enableSourcifyAbiLoader` or `loadVerifiedAbi`); import does not register a loader. `useSourcifyFallback` defaults to `false` |
| `@erc7730/sdk/lite` | Deprecated narrower entry of the same install. Omits the Sourcify client and `generateDescriptor` from that graph. Descriptor lookup is still `createOfficialRegistry()` / `{ pin }` |
| `@erc7730/sdk/viem` | `decodeViemTransaction` / `decodeViemTypedData` adapters (does not register a Sourcify loader) |

## Quick start

```ts
import {
  createOfficialRegistry,
  decodeTransaction,
  officialOnlyPolicy,
  VENDORED_REGISTRY_COMMIT,
} from '@erc7730/sdk';

// Defaults to VENDORED_REGISTRY_COMMIT. Production: pass an explicit pin.
const registry = createOfficialRegistry();
// const registry = createOfficialRegistry({ pin: VENDORED_REGISTRY_COMMIT });
const result = await decodeTransaction(tx, {
  registry,
  trust: officialOnlyPolicy(),
});

console.log(result.interpolatedIntent ?? result.intent);
console.log(result.source, result.confidence, result.trust.accepted);
console.log('default pin', VENDORED_REGISTRY_COMMIT);
```

The tarball does not ship a descriptor catalog. With no network, pass `indexes` and `cache`. ERC-20, ERC-721, and WETH builtins stay as local fallbacks.

Prefer [the wallet guide](/ERC-7730/guide/) for prefetch, `ExternalDataProvider`, `trustedTokens`, batch, and UserOp.
